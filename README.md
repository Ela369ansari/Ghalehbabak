# GhalehBabak | قلعه‌بابک

وب‌سایت شرکت راه و ساختمانی قلعه‌بابک.

- `index.html` نسخه فارسی است و `en.html` نسخه انگلیسی.
- متن‌ها، تیم، پروژه‌ها و اطلاعات تماس در پوشه `content/` نگه‌داری می‌شوند.
- عکس‌ها در پوشه `img/` هستند.

## ویرایش سایت با پنل مدیریت (Pages CMS)

۱. به **https://app.pagescms.org** بروید و با حساب GitHub وارد شوید.
۲. مخزن **ghalehbabak** را انتخاب کنید. بار اول باید به Pages CMS اجازه دسترسی به این مخزن را بدهید.
۳. در منوی کنار صفحه چهار بخش می‌بینید:
   - **اطلاعات تماس:** شماره مشاوره، شماره واتساپ، تلفن‌های دفتر و ایمیل‌ها.
   - **تیم:** افزودن، حذف یا جابه‌جایی اعضا و عوض کردن عکس، نام و سمت.
   - **پروژه‌ها:** دسته‌ها و عکس‌های گالری. برای عکس جدید، دکمه افزودن را بزنید و عکس را آپلود کنید.
   - **متن‌های سایت:** تمام عنوان‌ها و پاراگراف‌ها، بخش به بخش، با یک خانه برای فارسی و یک خانه برای انگلیسی.
۴. دکمه **Save** را بزنید. حدود یک دقیقه بعد سایت به‌روز می‌شود. اگر تغییر را نمی‌بینید، صفحه را رفرش کنید.

نکته‌ها:
- خانه‌های «کلید» و «شناسه» را تغییر ندهید.
- بهتر است عکس‌ها افقی باشند، با عرض حدود ۲۰۰۰ پیکسل. فرمت webp یا jpg مناسب است.
- در خانه «فارسی» فقط فارسی بنویسید و در خانه «English» فقط انگلیسی. هر زبان صفحه جداگانه خودش را دارد.
